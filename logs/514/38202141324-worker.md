What [#519](https://github.com/dokima-dev/dokima/pull/519) (the build for this issue) does:
- **Failed record:** when a run fails, a second job in `.github/workflows/agent.yml` checks whether the run posted its record. If it didn't, `unrecorded()` in `dokima/agent.py` turns the run's live card into a failed record that links the run and mentions you.
- **Needs you:** that same job updates the board from the failed record, so the card shows Needs you.
- **`/autopilot start`:** when the issue's last run has finished but left no record, it starts that run's stage again instead of saying nothing started.

2. **The word check reads every rules topic file.** This comes after story 1. Words a plan reviewer quotes only from a topic file must still pass the check. This story makes the change to the copy step in `agent.yml` that you allowed, so you still get the workflow change in story 2 as you said.

I put the word check before the rules split on purpose. That way, a quote that sits only in a topic file can't quietly start failing once the topics move.

**The blocker:** criterion 557.2's case for a branch behind main was too weak. The test only checked that a comment mentioning you contained the word "main". Every record already has that word in its icon links, so the case passed with nothing built.

- The test now strips HTML tags, links and web addresses from each comment first.
- What's left must mention you, say "main", and say the branch is behind, e.g. "behind" or "newest commit".
- As a contrast, the comments from the red-check run must not say that, so a message that always claims "behind" fails.
- I ran it against today's code: neither the behind-main run's comments nor the red-check run's comments pass, so the case can no longer pass by accident.

**Two other changes:**
- I reworded that edge case to say you are told "in words".

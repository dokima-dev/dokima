**Agent:** A new install now clears out the old Dokima code and workflows, so they stop running. All 8 tests in `tests/test_install.py` pass now; 4 of them failed before the change.

**What was wrong:** the installer added the new files but never deleted anything the earlier install had left behind.

**The fix**, in `dokima/playthrough.py`, inside the install step, before the new files are written:
- **829.1:** it deletes the old copy of Dokima's code (the `dokima/` folder). The repo's own files, like its README, are left as they were.
- **829.2:** it deletes every old workflow whose name matches one of Dokima's own. The repo's own workflows, like `ci.yml`, are left as they were, so the new workflow is the only Dokima one left.

One limit: an old Dokima workflow is only spotted if its name matches one Dokima ships today. A file under any other name stays.

I also ran the other two test files that cover this installer; all 25 tests pass. The full suite runs at the merge gate.

The hand-back is in `/tmp/dokima-out/work.json` and passes both checks. There were no raises to answer and I raised none.

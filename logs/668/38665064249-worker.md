**Agent:** I fixed the gap the code review found ([#701](https://github.com/dokima-dev/dokima/pull/701), the pull request for this story). A story's build now also waits while another story sharing a code file still has its worker running. Before, a story only counted as building once its worker had finished.

- **What changed:** `dokima/turns.py` now treats a story as building from the moment its worker starts. It looks for two signs posted after the story's last record: the autopilot "starting work" line, or the run's live Worker card. Either one makes a story sharing a code file wait.
- **Tests:** the new "worker still running" case in the 668.1 test failed before the change. Now `pytest -q tests/test_build_turns.py tests/test_worker_pr.py` gives 6 passed. I did not run the full suite; that runs at the merge gate.
- **Hand-back:** `work.json` is in `/tmp/dokima-out` and both hand-back checks pass. There were no open blockers to answer.

**One risk:** if a worker run crashes without ever writing its record, its live card stays up. That story would then block the others sharing its file until it is cleaned up or merges. I did not raise this.

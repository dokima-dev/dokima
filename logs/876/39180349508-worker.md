> 
> The README tells adopters to put `DOKIMA_APP_KEY` and `CLAUDE_CODE_OAUTH_TOKEN` in an Actions environment named `keys`. With the thin install (the adopter's `dokima.yml` calls `entry.yml@<tag>` in this repo, which calls the role workflows), those environment secrets never reach the jobs.

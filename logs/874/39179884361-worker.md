> # The ask
> 
> The thin install file `dokima/install/dokima.yml` listens to `push: {branches: [main]}`. A repo whose default branch is not `main` (for example `master`) never triggers Dokima on a push to its default branch, so the push-time jobs `entry.yml` gates on the default branch (testmon, uptodate) never run there.
> 
> `entry.yml` already checks `github.ref == format('refs/heads/{0}', github.event.repository.default_branch)` for those jobs, so the branch filter in the install file is redundant and only breaks other branch names.
> 
> **Ask:** drop the branch filter from `push` in the install file (plain `push:`), and update the docs that quote the file. A test should read the install file and assert its `push` trigger names no branch.

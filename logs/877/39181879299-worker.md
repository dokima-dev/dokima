> # The ask
> 
> `testmon.yml` builds its baseline with `python3 -m pytest -q --testmon` at the repo root, so pytest collects every test file in the repo. `full-suite.yml` runs `pytest ... tests` and the agent uses the `TESTS_DIR` setting. In a repo that keeps other test files outside the tests folder (for example a sandbox with its own dependencies), the baseline fails on imports the repo's real suite never needs, and testmon never gets a baseline.
> 
> **Ask:** run the testmon baseline over the same tests folder as the full suite (the `TESTS_DIR` setting, default `tests`). A test should read `testmon.yml` and assert its pytest call names that folder.

**Agent:** I've re-planned #584 with your wider scope. It's a split into 5 stories, and both plan checks pass. The plan is in `/tmp/dokima-out/plan.json`.

**The stories, 3 criteria each:**
1. **Draw:** one command draws a real issue's top card, run comments and autopilot comments, using any branch's code.
2. **Preview** (after 1): it posts the drawing as one comment on a [card-gallery](https://github.com/dokima-dev/card-gallery) issue and edits that same comment on later runs. It posts nothing to this repo.
3. **Compare and nightly** (after 1 and 2): it shows which lines differ from what main draws. Checks that touch real GitHub run nightly, never in a pull request's tests. The tool is never part of the product.
4. **Freeze** (after 2): your approval saves the drawing and the data it came from under `tests/fixtures/`. It then posts the final drawing on that drawing's issue in this repo, marked as its fixture record.
5. **Test** (after 4): a test redraws every fixture offline and fails on any difference, naming the first line that differs. Today's card code must redraw the approved [#557](https://github.com/dokima-dev/dokima/issues/557) card (to be made right) exactly.

The change is in `dokima/agent.py`, in the function that judges a pull request's head before merging:

- **Cancelled card runs:** a check named `card` that ended cancelled no longer counts. Any other cancelled check, such as All tests, still blocks the merge.
- **Failed checks:** a failed check still stops autopilot, and the reason names it, even when it fails after a wait.
- **Running checks:** autopilot checks again every 30 seconds for up to 45 minutes. It merges once every check passes. If a check is still running after 45 minutes, it stops and says which one. The 45 minutes is my own choice; nothing in the plan sets a limit.

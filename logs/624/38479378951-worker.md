It runs as `python3 tools/visuals.py draw ISSUE --branch BRANCH --repo OWNER/NAME`. It prints what that branch's code would post on a real issue:

- **Top card (624.1):** it checks the branch out into a temporary folder so your checkout isn't touched, then draws the card with that branch's code. The folder is removed afterwards. It only reads from GitHub and never writes there.
- **Run comments (624.2):** every record on the issue is drawn again with the branch's code. An issue with no records still gets its card.
- **Autopilot comments (624.3):** the autopilot lines, including merged-PR lines, and the replies to the autopilot start and stop commands are each drawn as the branch would word them.

**One limit:** an autopilot comment is recognised only if its text matches the lines in the checkout you run the command from. Run it from a checkout of main; a checkout whose lines differ would skip older autopilot comments without saying so.

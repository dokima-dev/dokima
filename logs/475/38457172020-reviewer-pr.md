- I replayed that step twice in a small test repo. Round one treats `tests/test_main.py` as main's, but round two lists it as one of the plan's own tests.
- Second rounds happen often: this issue went through three planner rounds.
- Fix: the planner adds a second-round case to the test for criterion 475.1, and the worker then fixes the code to pass it.

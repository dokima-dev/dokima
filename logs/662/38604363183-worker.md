**What changed** (all in the "Starting branch" step of `.github/workflows/agent.yml`):
- **Planner:** when the branch clashes with main and both sides changed the same test file, the planner now gets that file with conflict markers in it, to resolve. A clash only in other files leaves the planner's tests unmarked, as before.
- **Record of the hand-off:** the commit made for the planner lists each such test and main's version of it. A later planner run is not handed a clash it already resolved.
- **Worker:** when the worker merges main, it keeps the planner's resolution of a listed test, so that test is no longer on its list of clashes. The fence then finds no markers to reject it for. Clashes in other files, like the rules file, still go to the worker.
- **Guard:** if the planner left markers in a test, the worker does not keep that copy. The test stays on the clash list, and the hand-back fails saying which file still has markers, instead of the markers being pushed.
